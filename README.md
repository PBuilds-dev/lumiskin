# LumiSkin — Skincare Landing Page

A responsive skincare landing page built with plain HTML & Tailwind CSS, based entirely on self-made Figma mock up.

Live site: https://pbuilds-dev.github.io/lumiskin/

## Tools used
- HTML5 / Tailwind CSS (CDN)
- Figma (design reference)
- Squoosh (image optimization)
- GitHub Pages (hosting)
- GitHub Desktop

## Skills I practiced 
- Responsive layout weith Tailwind CSS Utility classes
- Google Fonts Integration
- Mobile-first design based on Figma mock up
- Semantic HTML5 structure
- Image optimization with Squoosh
- Static page deployment vit GitHub Pages
